# Hand tracking runtime and model

Runtime: @mediapipe/tasks-vision 0.10.32, Google MediaPipe, Apache-2.0.
Source: https://github.com/google-ai-edge/mediapipe
License: https://github.com/google-ai-edge/mediapipe/blob/master/LICENSE
Documentation: https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker

Pretrained model distribution:
https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task

The project uses the published pretrained model without training or fine-tuning.
The browser downloads these static files from the same origin as the application;
no webcam images are uploaded by this application.
