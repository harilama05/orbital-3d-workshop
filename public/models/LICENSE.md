# 3D asset credits

The workshop uses subsets of the following CC0 packs:

- Modular Spaceships and Space Fleet: https://3dassets.dev/packs/interstellar-fleet-modular-starships
- Mech Robots and Battle Hangar: https://3dassets.dev/packs/mech-hangar-and-battle-frames
- Mega Weapon Pack: https://3dassets.dev/packs/mega-weapon-pack
- Kenney Car Kit 3.1: https://kenney.nl/assets/car-kit

License: CC0 1.0 Universal — https://creativecommons.org/publicdomain/zero/1.0/
Original Kenney license text: ../licenses/kenney-car-kit.txt

Cruiser GLBs are retained from the source subset. Other models are separated into
assembly groups, transformed around mounting points and uniformly normalized.
Particle clouds, feature edges and SVG previews are derived from this geometry.
Source weapon animations are preserved as rigid part transforms; car wheel
rotation is authored by the application.

Assembly positions and compatibility rules are declared by this project using
source scenes, sockets and mount descriptions. The project root contains
MODEL-ASSET-AUDIT.md, asset-manifest.json and scripts/modular-evidence.json for
source provenance and preparation details.
